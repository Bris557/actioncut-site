# ActionCut app screenshots

What every screenshot in [`app-screenshots/`](app-screenshots/) shows. They are original captures from the Android app (ActionCut 1.5.41, October 7, 2026), in the light and the dark theme. The WebP copies on the site live in `static/img/` (the "Site" column below). The site itself isn't built from this folder.

The screens hold real data: hockey tournaments in Al Ain (Union Cup, Mirdif Ice Rink) and Bishkek, real kids on the ice, and a player-name tag ("Ivan"). Check before using them anywhere public.

Most screens show the event **Union Cup Al Ain**: Oct 4, 11:16, 3 h 48 min, 40 moments, tags Goal · Save · Assist · Funny · Skill.

## Camera app — `camera/`

The phone's own camera in video mode (MASTER · **VIDEO** · PHOTO, 1080·60, zoom 0.6–6) with ActionCut's orange floating button to the right of the shutter. The camera can't be screenshotted while it records, so the site draws this UI over game frames (`src/components/phone/CameraOverlayMock.tsx`).

| File | What's on screen |
|---|---|
| camera-with-button | The floating button with its count (40). |
| camera-with-quick-tags | Right after a tap: quick tags **Goal · Save · Assist** beside the button with the 5-second countdown bar, count 42. |
