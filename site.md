You are an expert full-stack web developer and UI/UX designer with a keen eye for modern, stylish, and user-friendly design. Your task is to generate the complete code (HTML, CSS, and JavaScript) for a single-page, responsive landing page for a new mobile application called ActionCut.

1. Project Overview: What is ActionCut?

ActionCut is a mobile app designed for athletes, parents, and sports videographers. It revolutionizes how they create highlight reels from long game footage. Instead of spending hours scrubbing through video, users can simply tap an overlay button on their screen during the event to mark key moments. The app then uses these timestamps to automatically cut and export a "greatest hits" video, saving hours of post-production work.

2. Design & Style Guidelines:

Overall Vibe: Modern, premium, clean, and dynamic. The design should feel energetic and tech-savvy.

Theme: Dark Mode. This creates a focused, cinematic feel.

Color Palette:

Background: A very dark, near-black charcoal (#121212).

Primary/Accent Color: A vibrant, energetic electric blue or cyan for buttons, links, and highlights (#00BFFF or similar).

Text Color: A slightly off-white for readability (#EAEAEA).

Secondary Text/Muted Color: A light gray (#888888).

Typography: Use a modern, clean sans-serif font from Google Fonts. "Poppins" would be a great choice for its mix of professionalism and style.

Layout: A single-page, responsive design that works flawlessly on desktop and mobile. Use plenty of white space (or in this case, "dark space").

Interactivity: Add subtle, smooth on-scroll animations (e.g., elements fading or sliding in as the user scrolls down). The navigation should smoothly scroll to the corresponding section.
